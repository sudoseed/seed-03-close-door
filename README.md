## 작품 소개

엘리베이터를 타고 1층에서 10층까지 올라갑니다. 층마다 문이 열리면 **닫힘 버튼을 연타**해서 최대한 빨리 문을 닫아야 합니다.

그런데 꼭 그럴 때 누군가 달려옵니다. **“잠깐만요!!”**

열어 주면 양심 점수가 오르지만 시간이 늦어집니다. 그냥 닫아 버리면 빨리 가지만 문틈 너머로 “…아.”가 들립니다.
10층에 도착하면 **SUDO SEED 승강기 윤리위원회**가 당신이 얼마나 이기적인 사람인지 아주 진지하게 판정해 드립니다.

```
$ ELEVATOR_OS v2.6 부팅 중...
$ 닫힘 버튼 연결 확인... OK
$ 탑승자 양심 모듈 로딩... 87%
$ 주의: 본 테스트 결과는 인사고과에 반영되지 않습니다(아마도).
```

## 게임 방법

1. **[탑승하기]** 를 누르면 1층에서 문이 열린 채로 시작합니다.
2. **닫힘 ▶|◀** 을 한 번 누를 때마다 문이 6~9%씩 닫힙니다. 손을 떼면 문은 초당 5%씩 **다시 열립니다**. 그러니까 연타해야 합니다.
3. 문이 끝까지 닫히면 “띵” 소리와 함께 다음 층으로 올라갑니다. **10층**에 도착하면 끝입니다.
4. 층마다 40% 확률로 누군가 달려옵니다(한 판에 최소 3번). 도착까지 **2.5초**가 남아 있고, 말풍선 아래 게이지로 보입니다.
   - **열림 ◀|▶** 을 누르면 태워 줍니다. 양심 점수가 오르고 **시간 +1.5초** 페널티를 받습니다.
   - 끝까지 닫아 버리면 빨리 갑니다. 대신 양심 점수가 깎이고, 문틈으로 짧은 한마디가 들립니다.
   - 도착할 때까지 문이 덜 닫혀 있으면 **문틈에 손을 넣습니다**. 문이 강제로 열립니다(양심 변화 없음).
5. 한 판에 딱 한 번, 닫힘 버튼이 **3초 동안 작동하지 않습니다**. 원래 그런 버튼도 있다고 합니다.

## 판정서

10층에 도착하면 **엘리베이터 탑승 태도 공식 판정서**가 발급됩니다.

- 문서번호(CD-2026-XXXXX), 발급일
- 기록: 총 소요 시간, 총 클릭 수, 최고 연타 속도(CPS), 양심 점수, 열어준 횟수 / 무시한 횟수, 속은 횟수 등
- **칭호 12종** 중 하나: `엘리베이터 성자`, `착한데 지각함`, `효율의 화신`, `상위 N%의 이기적인 사람` …
- 양심 점수와 소요 시간으로 계산한 **이기심 지수 / 양심 지수 상위 N%**
- 위원회의 진지한 한 줄 총평
- **SUDO SEED 승강기 윤리위원회** 도장 (경우에 따라 하나 더)

**결과 복사**를 누르면 판정 결과가 텍스트로 복사되고, **판정서 이미지 저장**을 누르면 PNG 파일로 내려받습니다.

## 이렇게 만들어졌습니다

- **순수 HTML / CSS / JavaScript**, 빌드 도구·프레임워크·외부 라이브러리 없음. 웹 폰트도 쓰지 않고 시스템 글꼴만 씁니다.
- **효과음**: 띵, 버튼 삑, 정원 초과 삐-, 도장 쾅 모두 Web Audio API로 그 자리에서 합성합니다. 음원 파일이 없습니다.
- **판정서 이미지**: Canvas API로 판정서와 도장을 직접 그려서 PNG로 저장합니다.
- **엘리베이터**: 금속 문은 CSS 그라데이션과 가는 세로줄, 층수판은 CSS로 만든 7세그먼트 LED, 사람은 이모지와 CSS 도형으로 그렸습니다. 이미지 파일은 로고와 파비콘뿐입니다.
- **모바일**: 연타할 때 더블탭 확대가 되지 않도록 `touch-action: manipulation`을 넣었습니다. 375px 폭에서도 버튼을 엄지로 누르기 편합니다.
- **동작 줄이기**: 기기에서 ‘동작 줄이기’를 켜 두면 흔들림, 튀어 오르기, 도장 애니메이션이 꺼지고 문은 즉시 움직입니다.
- 서버, 로그인, 유료 API를 쓰지 않습니다. 기록은 어디에도 전송되지 않습니다.
